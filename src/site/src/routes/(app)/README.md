# Application Routes

This route group contains authenticated application routes.

## Purpose

Routes in this group typically require authentication and use the application layout (with navigation, user menus, etc.).

## Examples

- Dashboard: `(app)/dashboard/+page.svelte`
- User profile: `(app)/profile/+page.svelte`
- Settings: `(app)/settings/+page.svelte`

## Layout

Add a `+layout.svelte` in this directory to define the shared layout for all application routes.
