# Marketing Routes

This route group contains public marketing and landing pages.

## Purpose

Routes in this group are typically public-facing pages that don't require authentication. They use a marketing-focused layout.

## Examples

- Homepage: `(marketing)/+page.svelte`
- About: `(marketing)/about/+page.svelte`
- Pricing: `(marketing)/pricing/+page.svelte`
- Contact: `(marketing)/contact/+page.svelte`

## Layout

Add a `+layout.svelte` in this directory to define the shared layout for all marketing routes.
