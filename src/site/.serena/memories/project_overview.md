# Project Overview

## Purpose

Modern SvelteKit starter template for building frontend web applications with Svelte 5. Includes full testing infrastructure, code quality tools, and modular feature system.

## Tech Stack

- **Framework**: SvelteKit 2.x with Svelte 5 (runes enabled)
- **Language**: TypeScript (strict mode)
- **Build Tool**: Vite 7.x
- **Testing**:
    - Vitest (unit and component tests)
    - Playwright (e2e tests)
- **Code Quality**: ESLint, Prettier
- **Adapter**: adapter-auto (supports multiple deployment targets)
- **Issue Tracking**: bd (beads)

## Key Features

- Svelte 5 runes and modern syntax
- Dual test setup (browser-based component tests + server tests)
- Modular feature system structure
- Full TypeScript strict mode
- Pre-configured dev tooling
